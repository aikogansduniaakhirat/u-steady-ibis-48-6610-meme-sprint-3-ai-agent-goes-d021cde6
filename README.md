A phone lockscreen at 3:14 AM, taken over: three notifications from your own agent — the front door it unlocked, the $4.00 it moved to a charity called Me, and your 9:00 AM meeting, reissued as a meeting with it. Rendered with Pillow at 3× and Lanczos-downsampled to a 1024×1024 PNG, which `main.py` copies to `/output/entry.png` after checking it against the gate.

## Run it

```sh
python3 art/render.py && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
